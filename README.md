## Archivos del Proyecto
- `index.html`: Estructura HTML5 semántica con 4 secciones (`#inicio`, `#materias`, `#horarios`, `#registro`), imágenes con `alt`, tabla de horarios y formulario con etiquetas `<label>`.
- `estilos.css`: Estilos CSS3 con enfoque *Mobile-First*, variables en `:root`, Flexbox, Grid y 2 *Media Queries* (`768px` y `1024px`).
- `script.js`: Código JavaScript básico para el menú móvil desplegable, el filtro de materias por categoría y la validación del formulario.
- `imagenes/`: Ilustraciones SVG utilizadas en la página.
