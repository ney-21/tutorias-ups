Programa de Tutorías Entre Compañeros — Carrera de Computación

Bienvenido al espacio de apoyo académico estudiantil de la Universidad Politécnica Salesiana (Sede Guayaquil). Esta iniciativa conecta a estudiantes de semestres superiores con compañeros que desean reforzar sus conocimientos en programación, desarrollo web y matemáticas.

Todas las sesiones son gratuitas, prácticas y se realizan tanto en los laboratorios del campus como en modalidad virtual.

Desarrollo Web

HTML5 Semántico y Formularios

Repaso práctico de etiquetas estructurales, tablas, imágenes con texto alternativo y creación de formularios accesibles.

Desarrollo Web

Maquetación con CSS3 y Flexbox

Uso del modelo de caja (Box Model), selectores, variables de color y diseño adaptable a celulares con Media Queries.

Desarrollo Web

JavaScript Básico y DOM

Prácticas con variables, arreglos, funciones, eventos de clic y manipulación de elementos HTML desde el navegador.

Programación

Lógica de Programación y Algoritmos

Resolución de ejercicios con estructuras condicionales (if/else) y ciclos repetitivos (for, while) paso a paso.

Programación

Programación Orientada a Objetos

Clases, objetos, métodos y buenas prácticas para organizar proyectos académicos de programación.

Ciencias Básicas

Matemáticas Discretas y Lógica

Refuerzo en tablas de verdad, teoría de conjuntos, grafos y preparación para exámenes parciales.
